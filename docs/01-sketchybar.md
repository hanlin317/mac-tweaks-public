# SketchyBar

## Base

The config is a modified **sketchybar-island** setup by garamnoh (MIT).
The original README and licence are kept as
[`config/sketchybar/UPSTREAM-README.md`](../config/sketchybar/UPSTREAM-README.md) and
[`config/sketchybar/LICENSE`](../config/sketchybar/LICENSE).

Main files:

| File | Purpose |
|---|---|
| `sketchybarrc` | Builds the bar, items, brackets and subscriptions |
| `config.sh` | The user-facing knobs: theme, height, opacity, wordmark, calendar, automax, Pilo, settings glyph |
| `colors.sh` | Palette |
| `2026-11-01-preferences.sh` | Runtime preferences for the settings popup |
| `plugins/` | Item renderers and popup generators |
| `helper/` | Swift helpers, Python planner and data files |

## Bar

- Position top, height `33`, `notch_display_height 33`, `margin 5`, `y_offset 5`, `topmost=window`,
  `sticky=on`, transparent background.
- The bar is drawn on all displays. On a notched MacBook the two islands sit either side of the
  notch; on a normal display the media island fills to 5 pt left of centre.
- Three brackets give the island backgrounds: left (spaces + app + cwd/git), work (focus +
  calendar + ready badges), right (agent/usage/audio/battery/wifi/clock/settings).
- Blur is intentionally off (`BAR_BLUR=0`): on macOS 27 blur turned the bar opaque after wake or a
  display change.

`~/.cache/sketchybar/`.

## Focus timer

- Item `focus`: icon `◷`, `icon.y_offset=3`, label `Focus`; label offset `0` so the word sits level
  with the active-app pill.
- Click opens the focus popup (`popup_click.sh focus`) with rows for 25 minutes, 50 minutes,
  pause/resume and reset.
- State lives in `2026-11-01-focus-state.py`; `2026-11-01-focus.sh` renders it.
- `update_freq` is dynamic: **1 s** while the timer runs, **30 s** idle. This is set by the script,
  so the `update_freq=1` in `sketchybarrc` is only the initial value.
- The glyph `◷` is not in JetBrains Mono and falls back to another font, so integer `y_offset`
  values cannot be pixel-perfect. Offset 3 is the calibrated value.

## Codex usage popup

`agent.sh` renders the Codex usage item and popup. The popup:

- 300 pt wide, 96 pt key column
- rows `5-hour` and `Weekly`
- two short footer rows
- independent amber/red thresholds per remaining percentage

## Task-ready badges

Bar-only badges for Codex and OpenCode completions. Hidden by default; display turns on when the
inbox has unacknowledged rows. See [04-task-ready.md](04-task-ready.md).

## Component timers

| Item | Interval |
|---|---|
| `clock` | 10 s (HH:MM) |
| `spaces` | 30 s + `space_change` / `display_change` |
| `front_app` | 30 s + `front_app_switched` |
| `agent` (Codex usage) | 30 s |
| `cal` | 30 s + `system_woke` |
| `wifi` | 30 s + `wifi_change` / `system_woke` |
| `bat` | 30 s + `power_source_change` |
| `audio` | 10 s + `volume_change` |
| `deepseek` | 300 s |
| `settings` | 15 s |
| `ready.watch` | 300 s fallback + `ai_ready` / `system_woke` / `front_app_switched` |
| `focus` | 1 s running / 30 s idle, set by the script |
| `theme`, `popups`, `cwd`, `git` | Event-driven |

The long intervals are deliberate: the bar used to poll spaces/front_app every 5 s, clock every 1 s
and agent every 15 s. The events already fire on change, so the polling is only a fallback.

## Helpers

Sources live in `config/sketchybar/helper/`. Build them with
[`scripts/build-helpers.sh`](../scripts/build-helpers.sh).

| `2026-11-01-tile-picker.swift` | Half companion picker + width cycling |
| `2026-11-01-menu-bar-coordinator.swift` | Menu-bar coordination used by the bar |
| `2026-11-01-calendar.swift` | Calendar access helper |

| `axmenu.swift` | Accessibility menu helper |
| `chromejs.swift` | Run JavaScript in Chrome |
| `clickaway.swift` | Click-away overlay helper |
| `displays.swift` | Display geometry |
| `events.swift` | Calendar event queries |

`build.sh` is the upstream build script. `scripts/build-helpers.sh` is the same idea with the
`arm64-apple-macos14.0` target and the Wi-Fi app bundle.

## Permissions

- **Accessibility**: needed by the helpers that read/move windows (display transfer, tile picker)
  and by BTT.
- **Screen Recording**: needed for window titles in the picker if it falls back to `CGWindowName`
  (the picker normally uses `AXTitle`, which does not).
- **Location**: `WifiScan.app` needs it to list nearby SSIDs; the app bundle exists only for that
  permission.
- **Calendar**: `2026-11-01-calendar.swift` / `CalendarAccess.app` needs Calendar access.

## Tuning

Most day-to-day knobs are in `config.sh`:

- `THEME`, `NOTCH_H`, `BAR_OPACITY`, `BAR_BLUR`, `WORDMARK`
- `TERMINAL_APP`, `NOTIF_APPS`
- `CAL_NEXT`, `CAL_WINDOW_MIN`, `HOLIDAY_CAL`
- `PILO_ISLAND`, `PILO_ANIM`
- `AUTOMAX`, `AUTOMAX_INCLUDE`, `AUTOMAX_EXCLUDE`
- `SETTINGS_GLYPH`, `SETTINGS_FONT`

The settings popup writes runtime preferences to `2026-11-01-preferences.sh`.
